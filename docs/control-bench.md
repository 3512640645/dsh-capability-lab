# control-bench · 判据、靶场与回归总闸

一句话：**"能操作电脑"必须是可复现的判据，不是主观说法。**
判据原文 = `tools/CONTROL-BENCH.md`；靶场 = `tools/arena/`；总闸 = `tools/run-regression.mjs`。

## 1. 能力分级与判据（照 CONTROL-BENCH 抄）

### L1 · 可靠

| 指标 | 判据 |
|---|---|
| 元素定位点击成功率 | **必须分通道报，禁止混算**：winctl 通道 ≥90%；naive 通道另列；不可度量样本显式剔除并说明 |
| 单步动作延迟 | **必须分通道**：naive p50 <1.5s / p90 <6s；winctl 另列 |

现况（现场重算 2026-11-07，35 份报告 450 runs）：winctl **84.9%**（零过滤）/ 89.4%（仅末次 repeat）/
98.1%（仅调参收敛批次）——**最有利的自洽口径仍不达 90%**；naive 51.6%；混算值 67.8% **不得作为能力读数**。

> 口径敏感度实测（X6 反证）：同一批数据在六种同样"合理"的口径下给出 **67.8% → 98.1%**，跨度 30 个百分点。
> **不写清"谁进分母、按哪条通道、取哪批报告"的成功率，不具备判定效力。**

### L2 · 熟练（本轮目标）——在自建靶场里 30 秒一局

| 指标 | 判据 |
|---|---|
| 命中数 | ≥ 20 / 30s |
| 命中率 | ≥ 90%（点中/总点击） |
| 平均反应时间 | ≤ 700ms（目标出现→点中，由靶场自己记录，不靠推算） |
| 连续局稳定性 | 3 局得分极差 ≤ 5 |

### L3 · 游戏级（进阶）

| 指标 | 判据 | 同批实测 |
|---|---|---|
| 复合动作序列 | 能完成"移动→瞄准→点击→按键→再移动"的定时序列 | 见第 2 节三层口径 |
| 视觉闭环频率 | 截图→识别→决策→点击 ≥ 2 Hz（单轮 ≤500ms） | 468ms = 2.14Hz ✓ |
| 目标会变 | 半径缩小/位置漂移时命中率仍 ≥70% | 100% ✓ |
| 长时稳定性 | 连续 3 分钟不掉速（前 30s 与最后 30s 差 ≤20%） | −2.38% ✓ |

## 2. ⚠️ 「定时序列偏差」必须分三层口径（两层会同时冤枉调度器、又放过插件）

**硬要求：三层数字必须来自同一批实验，并注明 run id 与数据文件名。三批拼凑的数据不算测量。**

| 口径 | 定义 | 判据 | 同批实测（l3-timing3.json，同局同源 QPC） |
|---|---|---|---|
| ① 调度精度 | `(实际k−实际0) − (计划k−计划0)`；**报 \|dev\|，不报有符号 dev** | 中位 ≤15ms、最大 ≤50ms | 11.260 / 42.102 ✅ |
| ② 注入延迟 | 「发出调用 → 目标收到」，同机 QPC，不含调度等待；**键盘/鼠标 × 消息/raw 四类分列并报 loss** | 中位 ≤5ms、p90 ≤10ms，loss=0 | 键盘 med 1.414 / p90 1.615 ✅；**鼠标 med 7.787 / p90 14.060 ❌**；raw **无数据** |
| ③ 端到端 | 靶场打点时刻 − 客户端计划时刻（跨进程/跨时钟） | 中位 ≤30ms、最大 ≤80ms | 28.525 / 67.025 ✅ |

**禁止事项**：只报其一；用键盘通道的数代表"注入延迟"整体；**把插件整条调用耗时（296–604ms）当投递延迟写进任一层**。

投递通道表（判据绑定通道）：

| 通道 | 投递本体 | loss | 需要前台 | 代价/限制 |
|---|---|---|---|---|
| 消息通道（PostMessage WM_CHAR / 键全序列） | 0.17–0.33ms | 0 | 否 | **raw 输入类目标收不到**（实测 rawInput 0–2/20） |
| SendInput（真实输入） | 0.53–1.29ms | 0（前台） | **是** | 失焦即 100% 丢失且不报错 |
| 常驻注入器（SetCursorPos + mouse_event） | 0.24–0.33ms | 0 | 是 | 需常驻进程；帧龄常量需标定 |
| 插件整条调用 | 296–604ms（键）/ 73–446ms（鼠） | — | 视 dispatch | 前置成本占 99.5%，**不是投递延迟** |

## 3. 跑靶场（测量必须遵守的四条）

```powershell
# 人在屏幕前玩（30s 一局，结束停结算面板，F5 再来，Esc 退出）
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File D:\dsh-plugin\tools\arena\arena.ps1

# 自动化：延迟 3 秒开局、25 秒一局、结束自动关窗
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File D:\dsh-plugin\tools\arena\arena.ps1 `
  -Duration 25 -StartDelayMs 3000 -ExitOnFinish

# 冒烟自检（元素通道打完一局再关窗）
& $node D:\dsh-plugin\tools\arena\tools\smoke.mjs
```

难度旋钮：`-TargetSize`（靶径，默认 56）`-MinMoveDistance`（默认 80，防原地连点）
`-Seed`（非 0 = 固定靶位序列，可复现同一局，便于 A/B 两通道打同一局）`-Width/-Height/-Left/-Top`（固定位置）。

四条硬规矩：**① 靶场自己写 run JSON**（`runs/run-<时间戳>.json`：hits/misses/avgReactionMs/reactions[]/targets[]）；
**② 禁止读靶场进程内存/日志预知下一个靶位**；**③ 每局开局前状态重置**（关上一局、重启）；
**④ 至少 3 局取中位数并报极差**。

报告格式：

```jsonc
{ "level": "L2", "runs": [ {"hits":23,"misses":2,"avgReactionMs":612} ],
  "median": {...}, "range": {...},
  "inputPath": "uia|vision|hybrid",
  "passes": { "hits>=20": true, "hitRate>=90%": true, "avgReaction<=700": true, "range<=5": true } }
```

> 注意口径：走元素通道时，靶场记的 `avgReactionMs` = **find + 点击 + 校验的整环开销**（实测 ≈1.5s），
> 不是纯点击延迟；纯 Invoke 分发 ≈170ms。跨通道对比必须写清走的是哪条通道。

## 4. 回归总闸（一次跑完所有可离线验证的检查）

```powershell
& $node D:\dsh-plugin\tools\run-regression.mjs                # 平衡档：1-4、7-11（跳过音频合成）
& $node D:\dsh-plugin\tools\run-regression.mjs --offline       # 只跑纯本地轻项：1-4、7-11，跳过第 6 项画廊
& $node D:\dsh-plugin\tools\run-regression.mjs --with-audio    # 全量档：1-11 全跑（含音频 ~55s）
& $node D:\dsh-plugin\tools\run-regression.mjs --keep-tmp      # 保留本次专属 tmp 供取证
```

退出码：**任一项 FAIL → 1；全过（含 SKIP）→ 0**。

12 项检查：1 视觉/输入自测 · 2 输入引擎纯函数自测 · 3 引擎语法 `node --check` · 4 引擎编译冒烟（16:9/9:16 `--html-only`）
· 5 音频（make-audio.py，断言 10/10 质检通过）· 6 画廊（断言 >100KB）· 7 质检脚本自检 · 8 质检夹具回归
（同相夹具必 PASS、反相与退化夹具必 FAIL）· 9 交付包陈旧性 · 10 最新成片质检 · 11 反应时延漂移闸门
· 12 核心簇 + 尾包率双指标闸门。

**三态读法（PASS/FAIL/SKIP）**：SKIP 只在"数据不存在/不足/过期"时出现，**绝不掩盖真实越线**。

* 第 11 项（漂移闸门）：对逐局 `avgReactionMs` 断言 a) 末局−首局 ≤ 首局×10%；b) 末局 ≤ 700ms；c) 越线局数=0。
  700ms 与 10% 是硬判据，不随数据放宽；无多局数据 → SKIP；数据源 mtime 距今 >6 小时 → 标 `STALE_DATA` 并降级 SKIP。
* 第 12 项（核心簇 + 尾包率）：a) 每局核心簇（样本 ≤800ms）中位 ≤ TH_CORE；b) >900ms 尾包率 ≤ TH_TAIL；
  c) 命中率 ≥ TH_HIT。三个阈值**全部由被检数据现场推导**（公式与过程随结果一起打印），并与冻结锚取**更严**的一侧生效：
  数据变差不放宽、数据变好自动收紧。数据不足（局数 <3 / 单局样本 <50 / 合并样本 <300）→ SKIP。

副作用约束：音频/画廊/成片质检的临时产物一律落**本次进程专属**的 `D:\dsh-tmp\run-<pid>-<ts>\`，
跑完清理；第 9 项只读不改交付包；第 10 项把最新成片**复制到 tmp 再质检**。

## 5. 本套东西的边界

靶场是**我们自己写的**，允许随便点、随便压测。联机游戏的反作弊会把自动化操作视为作弊，
这类判定是账号级不可逆的 —— 这是工程事实，不是道德说教。基准只在自己机器、自己写的靶场上跑。
